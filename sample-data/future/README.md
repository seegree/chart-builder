# sample-data/future

Data for renderers that are **explicitly not implemented yet**. The panel
will refuse these chart shapes today; the files exist so future renderers
ship with ready-made samples.

| File | Intended renderer | Status |
|---|---|---|
| `pie.csv` | Pie / donut | Not implemented — no renderer exists |
| `stacked-area.csv` | Stacked area | Not implemented — no renderer exists |

Everything in `sample-data/current/` works with the panel as shipped.
